## RazorpayX Users

To raise a support ticket:

1. Log in to the [RazorpayX Dashboard](https://x.razorpay.com/auth).
2. You can raise a ticket in two ways:

> [accordion] From My Account & Settings
>
> 1. Navigate to user profile icon at the top-right corner and click **My Account & Settings**.
> 2. Select **Support Tickets Inbox** and click **+ NEW QUERY**.
> 3. Select whether to:
>
>    * [**Raise a new request**](#raise-a-new-request).
>    * [**File a grievance**](#file-a-grievance).
>
>    Click **Next**.
>
>    ![Raise a new request or File a grievance](https://razorpay.com/docs/build/browser/assets/images/x-support-new-req-grievience.jpg)

> [accordion] Need Help Widget
>
> 1. Click the **Need Help?** button at the bottom-right corner of the screen.
> 2. Click **Write To Us** in the bottom menu. You can also browse through the FAQs/help articles to resolve your queries.
> 3. Select either of the following:
>
>    * [**Raise a new request**](#raise-a-new-request).
>    * [**File a grievance**](#file-a-grievance).
>
>    Click **Next**.

![My Account and Settings](https://razorpay.com/docs/build/browser/assets/images/x-support-profile.jpg)

### Raise a New Request

You can raise a request when you wish for help in setting up certain processes, enabling features or to report an issue.

1. Select the category of the issue from the drop-down menu.
2. Write a description of the issue faced for our better understanding and attach images if available.
3. Enter the email addresses of other users who you wish to keep informed.
4. Click **Submit**.

   ![Raise a new Support ticket](https://razorpay.com/docs/build/browser/assets/images/x-support-raise-new-request.jpg)

### File a Grievance

You can file a grievance when you are not satisfied with the support provided for a request you raised in the past.

1. Select the reason for you to file a grievance.
2. Mention your ticket reference number.
3. Click **Next**.

   ![Enter support ticket number](https://razorpay.com/docs/build/browser/assets/images/x-support-file-grievance-1.jpg)
4. Write a description of the complaint and expectations and click **Submit**.

   ![File a Grievance](https://razorpay.com/docs/build/browser/assets/images/x-support-file-grievance-2.jpg)

You have successfully raised a support request from the RazorpayX Dashboard.
