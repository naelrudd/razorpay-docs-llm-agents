# Payout Link APIs

> List of RazorpayX Payout Links API available to perform various actions.

Available in
🇮🇳 India

You can use our APIs to perform various actions required to make payouts. You can perform most of these actions from the [RazorpayX Dashboard](https://x.razorpay.com/auth) as well.

## List of APIs

The table below lists the various APIs and gives a brief description of each API:

| API Endpoint | Description |
| - | - |
| [Create Payout Links Using Contact Details](https://razorpay.com/docs/api/x/payout-links/create/use-contact-details.md) | Creates a Payout Link using customer's contact details like email id/mobile number. |
| [Create Payout Links Using Contact ID](https://razorpay.com/docs/api/x/payout-links/create/use-contact-id.md) | Creates a Payout Link using the Contact id of the customer. [Create a Contact](https://razorpay.com/docs/api/x/contacts.md) to generate the Contact id. |
| [Fetch All Payout Links](https://razorpay.com/docs/api/x/payout-links/fetch-all.md) | Retrieves the details of all Payout Links created. Use the query parameters to customise Payout Links retrieval. |
| [Fetch a Payout Link with ID](https://razorpay.com/docs/api/x/payout-links/fetch-with-id.md) | Retrieves the details of a particular Payout Link. |
| [Cancel a Payout Link](https://razorpay.com/docs/api/x/payout-links/cancel.md) | API to cancel an active Payout Link. |

> [!WARNING]
>
> **Watch Out!**
>
> Allowlisting your IP is mandatory for using the Payout Link APIs. Know how to [allowlist your IP](https://razorpay.com/docs/x/dashboard/allowlist-ip.md).
