# About RazorpayX Dashboard

> Switch Merchants, generate Reports, update Account Settings with the RazorpayX Dashboard.

Available in
🇮🇳 India

RazorpayX Dashboard is an easy to use and interactive page. It offers [Global Search](https://razorpay.com/docs/x/dashboard/global-search.md) and announcements for easy discoverability of new and existing features.

### Switch Merchant

To switch you merchant profile:

1. Go to Profile.
2. Click **Switch Merchant**.
3. Select the Merchant you want to switch to and wait for the page to refresh.

### My Account & Settings

| Tab | Actions |
| - | - |
| User Profile | <ul><li>To find and edit details like your username, password, phone number.</li><li>To disable or enable 2 FA.</li></ul> |
| Business Profile | <ul><li>To find business details like KYC status, business name and ID, website, tax details etc.</li><li>To set expiry for Payout Links.</li></ul> |
| Public Profile | To customise Payout Links display screen with a colour or logo of your choice and support details. |
| Banking | To find all your affiliated bank account details. |
| [Manage Team](https://razorpay.com/docs/x/manage-teams.md) | <ul><li>To enable 2FA for the team.</li><li>To add and assign roles to the team members.</li></ul> |
| Developer Controls | To [generate API keys](https://razorpay.com/docs/x/dashboard/api-keys.md) and edit webhooks. |
| [Support Tickets](https://razorpay.com/docs/x/support.md) Inbox | To raise queries in case of trouble and follow up on the existing ones. |
| Integrations | To [integrate with accounting tools](https://razorpay.com/docs/x/accounting) for easier reconciliation. |
