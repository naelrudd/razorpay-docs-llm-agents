# EdTech

> Explore Razorpay's recommended products for the educational institutions, ensuring secure and efficient transactions for seamless experiences.

Available in
🇮🇳 India

Manage payments and financial operations of your educational institution from a consolidated dashboard. Create an online platform, track payments, and create payouts within minutes.

### Education and E-Learning

Educational institutions and e-learning platforms can leverage RazorpayX for hassle-free fee collection. Automated receipts, timely reminders, and an easy-to-use interface simplify the payment process for students and parents.

> [accordion] Payout Links for Guest Instructors
>
> * Simplify payments using [Payout Links](https://razorpay.com/docs/x/payout-links), streamlining finance procedures.
> * Avoid bank details for one-time resources while maintaining proper records.

> [accordion] Easy Accounting Integration
>
> * Easy reconciliation of multiple payouts.
> * Utilize [Accounting Integration](https://razorpay.com/docs/x/accounting) with [Zoho Books](https://razorpay.com/docs/x/accounting/zohobooks.md) and [Tally](https://razorpay.com/docs/x/accounting/tally.md), along with downloadable [Account Statements](https://razorpay.com/docs/x/account-statement).
> * Enhance visibility, transparency, and team collaboration while ensuring consented access.

> [accordion] Manage Team and Custom User Roles
>
> * Assign roles and permissions to both vendors and freelancers, enhancing security and control.
> * [Custom User Roles](https://razorpay.com/docs/x/manage-teams/create-user-role.md) allow controlled access with or without [2FA](https://razorpay.com/docs/x/manage-teams/2fa.md).

> [accordion] Bulk Payouts for Refunds and Scholarships
>
> > [!WARNING]
> >
> > **Watch Out!**
> >
> > RazorpayX Lite is currently not available for new merchants. To set up a new RazorpayX account, refer to [Current Account](https://razorpay.com/docs/x/account-types/current-account.md).
>
> * Use [RazorpayX Lite or Current Account](https://razorpay.com/docs/x/account-types) and [Bulk Payout Links](https://razorpay.com/docs/x/payout-links/bulk.md) for convenient student incentive payouts.
> * Simplify rewards distribution using [Payout Links](https://razorpay.com/docs/x/payout-links) without the need for individual account details, improving efficiency.
