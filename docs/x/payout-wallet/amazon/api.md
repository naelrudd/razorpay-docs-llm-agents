# Payout Wallet - Amazon APIs

> List of RazorpayX Payouts Wallet APIs available to perform various actions.

Available in
🇮🇳 India

You can use our APIs to perform various actions necessary to create payouts. You can perform most of these actions from the [RazorpayX Dashboard](https://x.razorpay.com/auth) as well.

## List of APIs

The table below lists the various endpoints and gives a brief description of each:

| API Endpoint | Description |
| - | - |
| [Normal Payout API](https://razorpay.com/docs/api/x/payout-wallet/create/contact.md) Includes: <ol><li>[Create a Contact API](https://razorpay.com/docs/api/x/payout-wallet/create/contact.md)</li><li>[Create a Fund Account of type `wallet` API](https://razorpay.com/docs/api/x/payout-wallet/create/fund-account)</li><li> [Create a Payout API](https://razorpay.com/docs/api/x/payout-wallet/create/payout.md)</li></ol> | Creates a normal payout to your Contact's Amazon Pay Gift Card. |
| [Composite Payout API](https://razorpay.com/docs/api/x/payout-wallet/create/payout-composite.md) | Create a Contact, Fund Account and make the payout to your Contact's Amazon Pay Gift Card at once using [Composite API](https://razorpay.com/docs/api/x/payout-composite.md). |
