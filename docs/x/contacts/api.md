# Contact APIs

> List of RazorpayX Contact APIs available to perform various actions.

Available in
🇮🇳 India

You can use the our Contact APIs to create, update or deactivate contacts. You can perform most of these actions from the [RazorpayX Dashboard](https://x.razorpay.com/auth) as well.

## List of APIs

The table below lists the various Contacts APIs and gives a brief description of each API:

| API | Description |
| - | - |
| [Create a Contact](https://razorpay.com/docs/api/x/contacts/create.md) | Creates a new Contact. |
| [Update a Contact](https://razorpay.com/docs/api/x/contacts/update.md) | Updates an existing Contact. |
| [Activate or Deactivate a Contact](https://razorpay.com/docs/api/x/contacts/activate-or-deactivate.md) | Activates or deactivates an existing contact. |
| [Fetch all Contacts](https://razorpay.com/docs/api/x/contacts/fetch-all.md) | Retrieves all the Contacts. |
| [Fetch a Contact with ID](https://razorpay.com/docs/api/x/contacts/fetch-with-id.md) | Retrieves a single Contact with ID. |
