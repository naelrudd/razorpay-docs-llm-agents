# About APIs

> List of APIs available to perform various actions required to make payouts.

Available in
🇮🇳 India

You can use our APIs to make payouts. You can make payouts from the [RazorpayX Dashboard](https://x.razorpay.com/auth) as well.

## List of APIs

The table below lists the various APIs and gives a brief description of each API:

| API | Description |
| - | - |
| [Contacts APIs](https://razorpay.com/docs/x/contacts/api.md) | APIs to create, fetch details, update, activate, or deactivate a contact to whom payouts can be made. |
| [Fund Account APIs](https://razorpay.com/docs/x/fund-accounts/api.md) | APIs to create, fetch details, activate, or deactivate a fund account to which payouts are made. |
| [Account Validation APIs](https://razorpay.com/docs/x/fund-account-validation/api.md) | APIs to bank account and vpa creation and validation. |
| [Payout APIs](https://razorpay.com/docs/x/payouts/api.md#payout-apis) | APIs to create, fetch or cancel a payout made to a contact's fund account. |
| [Payouts to Cards APIs](https://razorpay.com/docs/x/payouts/api.md#payout-to-cards-apis) | APIs to make payouts to tokenised or unsaved cards. |
| [Composite APIs](https://razorpay.com/docs/x/payouts/api.md#payout-composite-api) | APIs to make payouts with just the contact details along with bank account details, UPI ID, or card details without having to create a fund account. |
| [Payout Link APIs](https://razorpay.com/docs/x/payout-links/api.md) | APIs to create payout links for contacts whose fund account details are not available. Payouts can be made by sending a payout link to the contact. |
| [Transaction APIs](https://razorpay.com/docs/x/account-statement/api.md) | API to fetch all transactions made on your business account. |
| [Fetch Balance API](https://razorpay.com/docs/api/x/account-validation/balance-fetch.md) | API to fetch account balance(s). |
| [Amazon Payout APIs](https://razorpay.com/docs/x/payout-wallet/amazon/api.md#list-of-apis) | APIs needed to make payouts via Amazon Pay. |
