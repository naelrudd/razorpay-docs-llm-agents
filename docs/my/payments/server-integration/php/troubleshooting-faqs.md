> [accordion] Why is the Pay button not appearing on my website/app after completing the SDK integration?
>
> The Pay button may not appear on your website/app if you are using an older SDK version. To resolve this, update the SDK with the latest version or replace the old lib/requests folder with the one from the latest SDK.

> [accordion] How do I integrate Razorpay Curlec with Laravel?
>
> You can integrate Razorpay Curlec with Laravel using [Razorpay Curlec PHP SDK](https://razorpay.com/docs/my/payments/server-integration/php.md) which is compatible with Laravel and other PHP frameworks.
