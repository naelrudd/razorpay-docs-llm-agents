# Supported Payment Methods

> Learn about the payment methods supported by Razorpay Curlec Subscriptions.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore
🇺🇸 United States

Razorpay Curlec Subscriptions supports the following payment methods:

* **Cards**: Customers enter their card details to authorise the subscription. The payment is then debited automatically based on the selected plan. Card authorisation uses 3DS.
* **Wallets**: Customers can pay using the [Touch'n Go](https://razorpay.com/docs/my/payments/payment-methods/wallets/touch-n-go.md) wallet.
