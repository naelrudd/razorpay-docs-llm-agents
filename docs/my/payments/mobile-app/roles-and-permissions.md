# Roles and Permissions

> Allow all user roles to access the app and differentiate the access level as per the role assigned.

Available in
🇮🇳 India
🇲🇾 Malaysia

The owner and admin of a Razorpay Curlec account can [assign user roles from the Razorpay Curlec web Dashboard](https://razorpay.com/docs/my/payments/dashboard/account-settings/manage-team.md#invite-a-new-user). Based on the role assigned, when users log in to the mobile app, they will have varying access permissions to access features, as mentioned below.
