# Settings

> Check the tabs available under settings on the Razorpay Curlec Payments Mobile App - Account details, API keys, Razorpay Curlec Assist and Support.

Available in
🇮🇳 India
🇲🇾 Malaysia

Following are the tabs available under Settings. You can:

* View your account details like:
  * Current Balance
  * Settlement Cycle
  * User Details
  * Business Details
* View API keys
* Contact Support
