# Settlements APIs

> List of Settlements APIs and Instant Settlements (On-demand Settlement) APIs available to perform actions.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore
🇺🇸 United States

You can use the Settlement APIs to perform various actions. You can perform a few of these actions from the Dashboard as well.

## List of Settlements API

The table below lists the various Settlement APIs and gives a brief description of each API:

| API | Description |
| - | - |
| [View All Settlements](https://razorpay.com/docs/my/api/settlements/fetch-all.md) | API to view all settlements |
| [View Settlements by Id](https://razorpay.com/docs/my/api/settlements/fetch-with-id.md) | API to view settlement details by providing the settlement id |
| Settlement Recon | API to view all transactions such as payments, refunds, transfers and adjustment settled to you for a particular day or month |
| [Create Instant Settlements](https://razorpay.com/docs/my/api/settlements/instant/create.md) | API to create an Instant Settlement |
| [View all Instant Settlements](https://razorpay.com/docs/my/api/settlements/instant/fetch-all.md) | API to view all Instant Settlements |
| [View Instant Settlements by id](https://razorpay.com/docs/my/api/settlements/instant/fetch-with-id.md) | API to view Instant Settlement details by providing the settlement id |
