Razorpay WooCommerce integration allows you to accept payments on your WordPress WooCommerce store using the Razorpay Curlec Payment Gateway plugin. This guide covers the prerequisites and setup steps to integrate Razorpay Curlec with WooCommerce, enabling UPI, Cards, Netbanking and Wallets payments.

**Before you proceed:**

* Create a [Razorpay Curlec account](https://accounts.curlec.com/auth/).
* Understand the [payment flow](https://razorpay.com/docs/my/payments/payment-gateway/how-it-works.md) process.
* Generate the [API Keys](https://razorpay.com/docs/my/api/authentication.md#generate-api-keys) from the Dashboard. To go live with the integration and start accepting real payments, generate Live Mode API Keys and replace them in the integration.
* Before installing the Razorpay WooCommerce subscription plugin, it is essential to have WooCommerce for subscriptions already installed.

> [!NOTE]
>
> **Handy Tips**
>
> * If you are not using WooCommerce, you can use our [native plugin for WordPress](https://razorpay.com/docs/my/payments/payment-gateway/ecommerce-plugins/wordpress.md).

## Supported Versions

* Wordpress v3.9.2 or higher
* WooCommerce v4.0 or higher
* PHP v7.0 or higher
* php-cURL

> [!NOTE]
>
> **Handy Tips**
>
> * Ensure you have the php-cURL extension installed to make the network calls required to use this plugin.
> * The plugin is tested using WooCommerce v8.6.1
