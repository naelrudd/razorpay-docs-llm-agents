# Issue an Invoice

> Issue Invoices to customers and receive payments.

Available in
🇮🇳 India
🇲🇾 Malaysia

A `draft` invoice can be issued to any one of the listed customers. Know more about [invoice states](https://razorpay.com/docs/my/payments/invoices/states.md).

## Issue an Invoice From Dashboard

To issue an invoice:

1. Log in to the Dashboard.
2. Click **Invoices**.
3. Search for the **Draft** invoice that you want to issue using the [search criteria](https://razorpay.com/docs/my/payments/invoices/search.md).
4. Select the **Invoice Id**.
5. On the right-hand side panel, click **Finalize and Issue**.
6. You can choose to send the invoice either by SMS or email or both by selecting the mobile number and email address.

   ![Select Medium to Send Invoices](https://razorpay.com/docs/build/browser/assets/images/invoices-invoice-issue.jpg)
7. Click **Issue Invoice**.

![Select Medium to Send Invoices](https://razorpay.com/docs/build/browser/assets/images/invoices-invoice-issue.jpg)

This sends the invoice to the customer along with a short URL called **Payment Link** using which the customer can make the payment.

## Issue an Invoice Using API

You can issue a `draft` invoice using [this](https://razorpay.com/docs/my/api/payments/invoices/issue.md) API.
