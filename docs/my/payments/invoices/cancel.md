# Cancel an Invoice

> Cancel an Invoice via Razorpay Curlec Dashboard or APIs.

Available in
🇮🇳 India
🇲🇾 Malaysia

You can cancel an unpaid invoice which is in `issued` state. A customer cannot make payments for the cancelled invoices. Know more about [invoice states](https://razorpay.com/docs/my/payments/invoices/states.md).

## Cancel an Invoice From Dashboard

To cancel an invoice:

1. Log in to the Dashboard.
2. Click **Invoices**.
3. Search for the invoice that you want to cancel using the [search criteria](https://razorpay.com/docs/my/payments/invoices/search.md). You can cancel invoices which are in `draft` or `issued` state.
4. Select the **Invoice Id**.
5. On the right-hand side panel, click the **Cancel Invoice** button.
6. On the **Cancel Invoice?** dialog box, click **Yes, Cancel** to confirm the cancellation.

![cancel invoice dialog box](https://razorpay.com/docs/build/browser/assets/images/invoices-invoice-cancel.jpg)

The cancelled invoices display a **Cancelled** status label.

## Cancel an Invoice Using APIs

You can cancel an unpaid invoice in `issued`state using [this](https://razorpay.com/docs/my/api/payments/invoices.md) API.
