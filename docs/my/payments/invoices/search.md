# Search an Invoice

> Search for an Invoice.

Available in
🇮🇳 India
🇲🇾 Malaysia

You can search for invoices (except those marked **Deleted**) on the Dashboard by specifying various filters. Know more about [invoice states](https://razorpay.com/docs/my/payments/invoices/states.md).

## Search an Invoice from the Dashboard

1. Log in to the Dashboard.
2. Select **Invoices** from the left menu and search for an invoice under **Invoices** by specifying filters.

![Invoice List](https://razorpay.com/docs/build/browser/assets/images/invoices-invoices-list-view.jpg)

| Filter | Description |
| - | - |
| Invoice Status | The status of the invoice |
| Invoice Id | Unique identifier of the invoice |
| Receipt No. | Receipt number of the invoice |
| Customer Contact | Registered contact of the customer |
| Customer Email | Email address of the customer |
| Notes | Additional information stored in the `Customer Notes` field while creating the invoice. |
| Currency Type | The type of currency used for creating an invoice. For example, Malaysian Ringgit. |

## Search an Invoice Using API

* View the list of all the invoices or the invoices raised for a customer using the [Fetch Multiple Invoices API](https://razorpay.com/docs/my/api/payments/invoices/fetch-all.md).
* View the details of an invoice by providing the invoice id using the [Fetch an Invoice API](https://razorpay.com/docs/my/api/payments/invoices/fetch-with-id.md).
