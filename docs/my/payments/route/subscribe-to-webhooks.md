# Subscribe to Webhooks

> Subscribe to various Webhook events related to Razorpay Curlec Route to receive instant notifications.

Available in
🇮🇳 India
🇲🇾 Malaysia

To subscribe to webhook events:

1. Log in to the Dashboard.
2. Navigate to **Accounts & Settings** → **Webhooks** to subscribe to any of the events mentioned in the following section.

## Webhook Events and Descriptions

| Webhook Event | Description |
| - | - |
| `transfer.processed` | Triggered when a transfer made to a Linked Account is processed. |
| `settlement.processed` | Triggered when a transfer made to a Linked Account is settled with the parent merchant. (Available only for [Razorpay Curlec Route](https://razorpay.com/docs/my/payments/route)). |
| `transfers.failed` | Triggered when a transfer made to a Linked Account is failed. |

Know more about [Webhooks](https://razorpay.com/docs/my/webhooks) and check the [sample payloads](https://razorpay.com/docs/my/webhooks/route.md).
