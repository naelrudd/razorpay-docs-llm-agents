# Payments APIs

> List of available Payments and Downtime APIs for various actions such as Capture, Fetch and Update.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore
🇺🇸 United States

You can use the Payments APIs to perform various actions. You can perform a few of these actions from the Dashboard as well.

## List of Payments APIs

The table below lists the various Payments APIs and gives a brief description of each API:

| API | Description |
| - | - |
| [Capture a payment](https://razorpay.com/docs/my/api/payments/capture.md) | API to capture a payment |
| [Fetch a payment](https://razorpay.com/docs/my/api/payments/fetch-with-id.md) | API to view details of a payment |
| [Fetch multiple payments](https://razorpay.com/docs/my/api/payments/fetch-all-payments.md) | API to get details of all payments |
| [Fetch payments based on orders](https://razorpay.com/docs/my/api/payments/fetch-payments-orders.md) | API to get payments based on orders |
| [Fetch card details for a payment](https://razorpay.com/docs/my/api/payments/fetch-card-details-payment.md) | API to get the card details for a payment |
| Update a payment | API to update notes of a payment |
| [Payment Downtime API](https://razorpay.com/docs/my/api/payments/downtime.md) | API for payment downtime and webhooks |
