# Search a Payment Button

> Search for a Payment Button on the Razorpay Curlec Dashboard.

Available in
🇮🇳 India
🇲🇾 Malaysia

You can search for a Payment Button on the Dashboard by specifying various filters.

To search for a Payment Button:

1. Log in to the Dashboard.
2. Select **Payment Button** from the left menu and search for a payment button under **Payment Button** by specifying filters.

| Filter | Description |
| - | - |
| Title | The title of the payment button. |
| Status | The state of the payment button. Know more about [Payment Button states](https://razorpay.com/docs/my/payments/payment-button/states.md). |
