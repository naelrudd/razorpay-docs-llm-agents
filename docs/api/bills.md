# About Bills

> API Documentation for Razorpay bills. Create, Update and Delete Bills using APIs. Check the various use cases and code samples.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore
🇺🇸 United States

You can use Razorpay [Billme](https://razorpay.com/docs/pos/billme) to create digital bills and share them with your customers.

Fork the Razorpay Postman Public Workspace and try the Bills APIs using your [Test API Keys](https://razorpay.com/docs/payments/dashboard/account-settings/api-keys.md).

[![Run in Postman](https://run.pstmn.io/button.svg)](https://www.postman.com/razorpaydev/razorpay-public-workspace/folder/12492020-43632330-6e4d-4cf5-b2e4-14f278e72f46?action=share\&source=copy-link\&creator=19311422)

> [card] [Create a Bill](https://razorpay.com/docs/api/bills/create.md)
>
> `POST` `/v1/bills`
>
> Creates a Bill.

> [card] [Update a Bill](https://razorpay.com/docs/api/bills/update.md)
>
> `PATCH` `/v1/bills/:bill_id`
>
> Updates the details of a Bill.

> [card] [Delete a Bill](https://razorpay.com/docs/api/bills/delete.md)
>
> `DELETE` `/v1/bills/:bill_id`
>
> Deletes a Bill.
