# Documents

> Securely send dispute-related documents to Razorpay using the Documents API.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore

Use the Documents APIs to securely upload and share documents with Razorpay.\
\


Fork the Razorpay Postman Public Workspace and try the Documents APIs using your [Test API Keys](https://razorpay.com/docs/api/authentication.md#generate-api-keys).

[![Run in Postman](https://run.pstmn.io/button.svg)](https://www.postman.com/razorpaydev/workspace/razorpay-public-workspace/folder/12492020-c8192d5e-7fd8-4047-a6c4-eb2ef5e34155)

> [card] [Create a Document](https://razorpay.com/docs/api/documents/create.md)
>
> `POST` `/v1/documents`
>
> Uploads a document onto the Razorpay ecosystem.

> [card] [Fetch Document Information](https://razorpay.com/docs/api/documents/fetch-info.md)
>
> `GET` `/v1/documents/:id`
>
> Retrieves the details of any document that was uploaded.

> [card] [Fetch Document Content](https://razorpay.com/docs/api/documents/fetch-content.md)
>
> `GET` `/v1/documents/:id/content`
>
> Downloads a previously uploaded document.
