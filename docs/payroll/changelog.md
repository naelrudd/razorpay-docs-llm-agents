The following table records changes made to RazorpayX Payroll since Jan 2024:

| Month-Year | Feature | Description |
| - | - | - |
| May 2026 | Flexible Benefits | Introduced the [Flexi Component Library](https://razorpay.com/docs/payroll/component-library/flexible-benefits.md) to define and manage Flexible Benefit Plan (FBP) components such as Meal Allowance, Car Lease Reimbursement and Employer NPS Contribution. |
| April 2026 | Multiple Salary Structures | Create and manage [multiple salary structures](https://razorpay.com/docs/payroll/multiple-salary-structure.md) across employee groups, along with new [Compensation](https://razorpay.com/docs/payroll/compensation.md) pages for CTC components, Flexi components, Perquisites and Recurring Deductions. |
| April 2026 | Tax Codes | Map TDS codes to salary components using the [Tax Codes](https://razorpay.com/docs/payroll/tax-verifications/tax-codes.md) setup for accurate tax filings. |
| Feb 2026 | Salary Component Library | Expanded the [Salary Component Library](https://razorpay.com/docs/payroll/component-library.md) with Deduction, Non-Payable Benefits and Perquisites categories, alongside Earnings. 18 predefined deduction components are now available. |
| Dec 2025 | Multi-location ESI | Set up, pay and check [ESI compliance payments across multiple locations](https://razorpay.com/docs/payroll/multi-location-esi.md). |
| April 2025 | Form 24Q | Payroll introduced check for  [accurate 24Q filing.](https://razorpay.com/docs/payroll/tds/form-24Q.md) |
| March 2025 | Salary Component Library | Create [custom salary components](https://razorpay.com/docs/payroll/component-library.md) for your organisation. |
| Feb 2025 | Provident Fund | Payroll has resumed automated registration and PF payments for employees. This was paused due to 2FA rule on the PF portal. |
| Dec 2024 | Tax Deductions | Create [investment declaration and proof upload windows](https://razorpay.com/docs/payroll/tax-deductions-setup.md) for your organisation. |
| Nov 2024 | 2FA | Introduced [2-factor authentication](https://razorpay.com/docs/payroll/administrator#two-factor-authentication) for the following actions:  <ul><li>[Contractor Payments](https://razorpay.com/docs/payroll/payroll-payouts.md#contractor-payments)</li><li>[User role creation](https://razorpay.com/docs/payroll/user-roles-workflows.md#create-user-roles)</li><li>[Payroll execution](https://razorpay.com/docs/payroll/run-payroll.md#execute-payroll)</li><li>[Pay advance salary](https://razorpay.com/docs/payroll/advance-salary.md#pay-advance-salary)</li><li>[Pay reimbursements](https://razorpay.com/docs/payroll/reimbursements.md#pay-reimbursements)</li><li>[Create an employee loan](https://razorpay.com/docs/payroll/loans.md#create-a-loan)</li><li>API access</li> </ul>  |
| Sep 2024 | Professional Tax | Due to mandatory 2FA implementation by the Karnataka Government, [automated PT payments](https://razorpay.com/docs/payroll/professional-tax.md#pt-payment-for-karnataka-employees) via Payroll for employees residing in Karnataka are temporarily paused. |
| Aug 2024 | Provident Fund (PF) | Due to mandatory 2FA implemented by the EPFO, [automated PF payments and registration](https://razorpay.com/docs/payroll/faqs#pf-payments) for employees via the Payroll Dashboard is temporarily paused. |
| Aug 2024 | 2FA | Introduced mandatory [2-factor authentication](https://razorpay.com/docs/payroll/administrator#two-factor-authentication) for administrators and user roles during login when accessing the Payroll Dashboard for secure money movement. |
| Aug 2024 | Budget Changes | Revised the payroll calculations per the [changes introduced](https://razorpay.com/docs/payroll/run-payroll.md) in the Union Budget for the new regime. |
| July 2024 | LWF | Introduced [enabling LWF for employees](https://razorpay.com/docs/payroll/statutory-compliance#labour-welfare-fund-lwf) from their profiles. |
| May 2024 | Fund Loading | Introduced Source Account Validation to ensure secure fund transfer and payments. |
| May 2024 | Approval Workflow | You can set up [approval workflow](https://razorpay.com/docs/payroll/approval-workflow.md) and add approvers for core payroll and salary revision actions. |
