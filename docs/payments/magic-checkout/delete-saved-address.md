# Delete a Saved Address on Magic Checkout

> Remove a delivery address you saved while shopping on a store that uses Razorpay Magic Checkout. No payment or order is needed.

Available in
🇮🇳 India

You can remove any delivery address you saved while shopping on a store that uses Razorpay Magic Checkout. It takes about a minute, and you do not need to pay or place an order.

## Delete an address

1. Open the [Razorpay demo page](https://razorpay.com/demopg3/). At the bottom of the page, select **Magic Checkout** and **Mobile**, then click **Buy Now**.

   ![Demo page toggles with Magic Checkout and Mobile selected](https://razorpay.com/docs/build/browser/assets/images/magic-checkout-delete-address-demo-toggle.png)

2. Enter the mobile number you shop with, then enter the OTP you receive.

3. Tap **Add/Change** next to the delivery address.

   ![Magic Checkout order summary with the Add/Change link next to the delivery address highlighted](https://razorpay.com/docs/build/browser/assets/images/magic-checkout-delete-address-add-change.png)

4. Tap **⋮** on the address you want to remove, then tap **Delete**.

   ![Saved delivery addresses list with the three-dot menu open and the Delete option highlighted](https://razorpay.com/docs/build/browser/assets/images/magic-checkout-delete-address-menu.png)

5. Tap **Yes, delete**. The address disappears from your list.

   ![Confirmation prompt asking if you want to delete this address, with the Yes, delete button highlighted](https://razorpay.com/docs/build/browser/assets/images/magic-checkout-delete-address-confirm.png)

Repeat steps 4 and 5 for each address you want to remove. Close the page when you have finished. You do not need to complete the payment.

> [!NOTE]
>
> After you delete an address, it no longer appears at checkout on any store that uses Razorpay Magic Checkout.
