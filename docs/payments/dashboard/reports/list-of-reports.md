# List of Standard Reports

> Check and download the various types of Reports available on the Razorpay Dashboard.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore
🇺🇸 United States

The table below lists the various reports supplied as default and gives a brief description of each report. Click the report name to download the sample report of that product. Know [how to download reports.](https://razorpay.com/docs/payments/dashboard/reports.md#download-reports)

## Payment Gateway

| Report Name | Description |
| - | - |
| [Settlements](https://razorpay.com/docs/build/browser/assets/images/sample-settlements-report.xlsx) | This report provides a list of the settlement(s) in the selected time range. |
| [Payments](https://razorpay.com/docs/build/browser/assets/images/sample-payments-report.xlsx) | This report provides details of all payments created within the selected time range. It also helps you verify whether a payment is international or domestic. |
| [Combined Report](https://razorpay.com/docs/build/browser/assets/images/sample-combined-report.xlsx) | This report provides all transactions (payments, refunds, adjustments and transfers) and settlements made in the selected time range. |
| [Orders](https://razorpay.com/docs/build/browser/assets/images/sample-orders-report.xlsx) | This report provides details of all orders that were created in the selected time range. |
| [Refunds](https://razorpay.com/docs/build/browser/assets/images/sample-refunds-report.xlsx) | This report provides details of all refunds that were initiated in the selected time range. |
| [Instant Refunds](https://razorpay.com/docs/build/browser/assets/images/sample-instant-refunds-report.xlsx) | This report provides details of all the instant refunds initiated in the selected time range. |
| [Settlement Recon](https://razorpay.com/docs/build/browser/assets/images/sample-settlements-recon-report.xlsx) | This report provides a detailed list of all transactions (payments, refunds, and adjustments) against every settlement in the selected time range. |
| [Monthly Invoice](https://razorpay.com/docs/build/browser/assets/images/sample-monthly-invoice-report.xlsx) | An invoice for transactions and the corresponding payments. |

> [!NOTE]
>
> **Handy Tips** You can currently download only the Monthly Invoices report.
