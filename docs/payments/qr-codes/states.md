# QR Code States

> List of QR Code states. Find descriptions for active and closed states.

Available in
🇮🇳 India

A QR Code can be in one of two states: `active` or `closed`.

## QR Codes States and Descriptions

The table below lists the various states of a QR Code and gives a brief description of each state:

| Status | Description |
| - | - |
| `active` | Indicates that the QR Code has been created and is ready to accept payments. Know more about [creating a QR Code.](https://razorpay.com/docs/payments/qr-codes/create.md) |
| `closed` | Indicates that the QR Code has been closed. Customers cannot make payments using a closed QR Code. Know more about [closing a QR Code.](https://razorpay.com/docs/payments/qr-codes/close.md) |
