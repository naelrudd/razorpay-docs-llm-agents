# Standard Payment Links

> Create Standard Payment Links and share them with your customers through SMS and emails.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore
🇺🇸 United States

You can send the Standard Payment Links as URLs to customers through SMS and emails. Customers can open these URLs and make payments using netbanking, cards, wallets, UPI and bank transfer payment methods.

You can also use [UPI Payment Links](https://razorpay.com/docs/payments/payment-links/upi.md) to receive UPI payments.

## Payment Link States

Know about the different [Standard Payment Link states](https://razorpay.com/docs/payments/payment-links/states.md#standard-payment-links).

## Create

Create a Standard Payment Link from the [Dashboard](https://razorpay.com/docs/payments/payment-links/create.md#create-a-standard-payment-link-from-dashboard) or using our [APIs](https://razorpay.com/docs/api/payments/payment-links/create-standard.md).

## Standard Payment Link Vs. UPI Payment Link

You can also use [UPI Payment Links](https://razorpay.com/docs/payments/payment-links/upi.md) to receive UPI payments. The table below lists the applicable features for Standard and [UPI Payment Links](https://razorpay.com/docs/payments/payment-links/upi.md):

| Features | Standard Payment Links | UPI Payment Links |
| - | - | - |
| Reminders for Payment Links | ✔ | ✔ |
| Partial Payments | ✔ | ✘ |
| Bulk Upload | ✔ | ✔ |
| Customise Payment Links | ✔ | ✘ |
| Offers on Payment Links | ✔ | ✘ |
| Receive Payments via Bank Transfer | ✔ | ✘ |
