> [tab] iOS SDK
>
> UPI apps supported on the Razorpay iOS SDK, with their shortcodes and URL schemes. Add each URL scheme, without `://`, to `LSApplicationQueriesSchemes` in your app's `info.plist` file.

> > [!NOTE]
> >
> > **Pass only the shortcode**
> >
> > On the iOS SDK, `upi_app_package_name` must contain only the shortcode that the SDK returns in `getAppsWhichSupportUpi()`. For example, pass `google_pay` for Google Pay.
