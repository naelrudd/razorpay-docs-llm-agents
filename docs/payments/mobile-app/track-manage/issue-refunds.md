# Issue Refunds

> Issue refunds to customers using the Razorpay Payments Mobile App and check the various refund states.

Available in
🇮🇳 India
🇲🇾 Malaysia

You can use the Razorpay Payments Mobile app to issue partial or full refunds to your customers.

## How to Issue a Refund

Watch this video to see how to issue a refund.

  <source src="https://razorpay.com/docs/build/browser/assets/images/issue-refund.mp4" title="Issue a refund on Razorpay Mobile App" type="video/mp4" />

  Business Verification for a Registered Business
</video>

Follow these steps to issue a refund:

1. Log in with your Dashboard credentials. You can also use the **Login With Google** option. If you have enabled the 2FA feature on your account, complete the OTP process. \


   ![Payments Mobile App Login](https://razorpay.com/docs/build/browser/assets/images/payments-mobile-app-login.jpg)
2. Navigate to **Transactions** → **Payments**. Tap on the payment for which you have to issue a refund.\

3. Tap **Issue Refund**.

   ![Issue Refunds using Razorpay Mobile App](https://razorpay.com/docs/build/browser/assets/images/payments-mobile-app-refund.jpg)
4. Provide the following details:
   * Enter the refund amount. You can choose to make a full or partial refund.
   * Select **Refund Instantly** if you want the refund to reach the customer within a day's time.

> [!NOTE]
>
> **Handy Tips**
>
> * Instant refund carries additional fees.
> * This feature is available only on Netbanking, UPI and select debit and credit cards. [Check the complete list of payment methods.](https://razorpay.com/docs/payments/refunds/instant.md#payment-methods)

* You can add a comment. This is an optional field.

5. Tap **Issue Full/Partial Refund**.\

6. Tap **Yes, Issue Refund** to confirm. You get a confirmation popup as shown: \


   ![successful refund](https://razorpay.com/docs/build/browser/assets/images/payments-mobile-app-success-refund.jpg)
7. To view the details, tap on the payment for which you initiated a refund.

## Refund States

The table below lists the various states in the refund life cycle and provides a brief description about each.

| Status | Description |
| - | - |
| Pending | Razorpay is attempting to process the refund. |
| Processed | Once the refund has been processed, it goes to the `processed` state. |
