# Shopify Plugin Prerequisites

> Know how to integrate Razorpay Payment Gateway with your Shopify store. Complete guide for Shopify payment integration with Razorpay Secure app.

Available in
🇮🇳 India

> [!WARNING]
>
> **Plugin Renamed**
>
> In your Shopify admin, the Razorpay plugin is listed as **01 Cards, UPI, NB, Wallets by Razorpay**. To install it, go to **Settings** → **Payments** → **Add payment method**, click **Search by provider** and search for **01 Cards, UPI, NB, Wallets by Razorpay**. Your customers see it at checkout as **Razorpay Secure (UPI, Card, Int'l Card, Apple Pay)**. The plugin was earlier listed as **1Razorpay - UPI, Cards, Wallets, NB** and **All-in-one Razorpay Payment Gateway**.

Razorpay Shopify integration allows you to accept payments on your Shopify store using the Razorpay Secure app. This guide covers how to integrate Razorpay with Shopify, enabling UPI, Cards, Wallets and Netbanking payments.

**Before you proceed:**

* Create a [Razorpay account](https://dashboard.razorpay.com/signup).
* Sign up for a [Shopify account](https://www.shopify.in).
* [Ensure that your website](https://razorpay.com/docs/payments/dashboard/account-settings/business-website-details.md#add-and-edit-website/app/additional-websites) is reviewed before initiating integration with Shopify.
* A Razorpay Account with access to the account owner’s credentials. (Only owners can connect Razorpay with Shopify, and API keys are not required for integration.)
