**Before you proceed:**

* Create a [Razorpay account](https://dashboard.razorpay.com/signup).
* Understand the [payment flow](https://razorpay.com/docs/payments/payment-gateway/how-it-works.md) process.
* Generate the [API Keys](https://razorpay.com/docs/api/authentication.md#generate-api-keys) from the Dashboard. To go live with the integration and start accepting real payments, generate Live Mode API Keys and replace them in the integration.

## Supported Versions

We support the following versions of OpenCart with separate extensions: OpenCart 4, OpenCart 3, OpenCart 2 and OpenCart 1.5.

## Supported Products

Razorpay OpenCart Plugin is only supported on Web Standard Checkout and the following products:

| Plugin | Payment Gateway | Route | Subscriptions |
| - | - | - | - |
| OpenCart 1.5 | ✓ | x | x |
| OpenCart 2 | ✓ | x | x |
| OpenCart 3 | ✓ | x | ✓ |
| OpenCart 4 | ✓ | x | ✓ |
