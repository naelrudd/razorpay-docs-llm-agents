## Integration Steps

**Before you proceed:**

<ul>
  <li>Create a [Razorpay account](https://dashboard.razorpay.com/signup). </li>
  <li>Generate the [API Keys](https://razorpay.com/docs/payments/dashboard/account-settings/api-keys.md#generate-api-keys) from the Dashboard. To go live with the integration and start accepting real payments, generate Live Mode API Keys and replace them in the integration.</li>
  <li>Know about the [Payment Flow](https://razorpay.com/docs/payments/payment-gateway/how-it-works.md).</li>
</ul>

Follow these integration steps:

> [card] [1. Build Integration](https://razorpay.com/docs/payments/payment-gateway/flutter-integration/standard/integration-steps.md#1-build-integration)
>
> Integrate Flutter Standard SDK.

> [card] [2. Test Integration](https://razorpay.com/docs/payments/payment-gateway/flutter-integration/standard/integration-steps.md#2-test-integration)
>
> Test the integration by making a test payment.

> [card] [3. Go-live Checklist](https://razorpay.com/docs/payments/payment-gateway/flutter-integration/standard/integration-steps.md#3-go-live-checklist)
>
> Check the go-live checklist.

> [card] [Sample App](https://github.com/razorpay/razorpay-flutter/blob/master/example/lib/main.dart)
>
> Check the sample app to integrate on GitHub.
