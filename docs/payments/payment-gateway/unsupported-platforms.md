# Unsupported Platforms and Integrations

> Learn how to integrate Razorpay Payment Gateway with platforms that don't have an official plugin. Explore alternate integration options and workarounds.

Available in

🇸🇬 Singapore

> [!WARNING]
>
> **Razorpay does not have an official plugin for every platform**
>
> If the platform you are looking for is not in [Razorpay's official plugin directory](https://razorpay.com/docs/payments/payment-gateway/ecommerce-plugins), there is no officially supported integration for it. You can still integrate Razorpay using the API directly — see the Alternate Options below.

Razorpay has official plugins and SDKs for a specific set of platforms. If your platform is not listed in [Razorpay's official plugin directory](https://razorpay.com/docs/payments/payment-gateway/ecommerce-plugins), Razorpay does not have an official integration for it.

The list below shows examples of commonly requested platforms that do not have an official integration. It is not exhaustive — the absence of a platform from this list does not mean an official integration exists for it.

* Shiprocket
* WhatsApp API/WhatsApp Pay
* Typof
* Google Ads Enhanced Conversion
* Notion
* Webflow
* Framer

## Alternate Options

* **Custom Payment Gateways**: If your platform supports custom payment gateways, use our [Web Integration (Standard Checkout)](https://razorpay.com/docs/payments/payment-gateway/web-integration/standard/integration-steps.md) directly. No other plugin is needed.
* **Custom Integration**: Check Razorpay's [Official Plugin list](https://razorpay.com/docs/payments/payment-gateway/ecommerce-plugins). If yours isn't there, you can build a [custom integration using the Standard Checkout API](https://razorpay.com/docs/payments/payment-gateway/web-integration/standard.md).
* To request an official integration: [Contact support](https://razorpay.com/support/#request) with your platform details.
