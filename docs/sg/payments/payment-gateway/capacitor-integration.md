# Capacitor Standard SDK Prerequisites

> Check the prerequisites before you integrate with Razorpay Capacitor Standard SDK.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore

> [card] [Troubleshooting & FAQs](https://razorpay.com/docs/sg/payments/payment-gateway/capacitor-integration/troubleshooting-faqs.md)
>
> Troubleshoot common error scenarios and find answers to frequently asked questions about Capacitor Standard integration.

You can use Razorpay Standard SDK to integrate the Razorpay Payment Gateway with your Capacitor Application to accept payments. The Razorpay Capacitor plugin acts as a wrapper around our native Android and iOS SDKs.

> [!TIP]
>
> **Update SDK**
>
> Check your [current SDK version](https://razorpay.com/docs/sg/payments/payment-gateway/capacitor-integration/troubleshooting-faqs.md#how-can-i-check-the-razorpay-capacitor-standard-sdk-version). If it is outdated, please [update the SDK](https://razorpay.com/docs/sg/payments/payment-gateway/capacitor-integration/troubleshooting-faqs.md#how-can-i-update-the-razorpay-capacitor-standard-sdk-version) to ensure uninterrupted settlements of your funds.

## Integration Steps

**Before you proceed:**

<ul>
  <li>Create a [Razorpay account](https://dashboard.razorpay.com/signup). </li>
  <li>Generate the [API Keys](https://razorpay.com/docs/sg/payments/dashboard/account-settings/api-keys.md#generate-api-keys) from the Dashboard. To go live with the integration and start accepting real payments, generate Live Mode API Keys and replace them in the integration.</li>
  <li>Know about the [Payment Flow](https://razorpay.com/docs/sg/payments/payment-gateway/how-it-works.md).</li>
</ul>

Follow these integration steps:

> [card] [1. Build Integration](https://razorpay.com/docs/sg/payments/payment-gateway/capacitor-integration/integration-steps.md#1-build-integration)
>
> Integrate Capacitor Standard SDK.

> [card] [2. Test Integration](https://razorpay.com/docs/sg/payments/payment-gateway/capacitor-integration/integration-steps.md#2-test-integration)
>
> Test the integration by making a test payment.

> [card] [3. Go-live Checklist](https://razorpay.com/docs/sg/payments/payment-gateway/capacitor-integration/integration-steps.md#3-go-live-checklist)
>
> Check the go-live checklist.
