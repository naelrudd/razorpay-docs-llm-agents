# React Native Standard Plugin Prerequisites

> Check the prerequisites before you integrate Razorpay React Native Standard plugin with our native Android and iOS SDKs.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore

> [card] [Troubleshooting & FAQs](https://razorpay.com/docs/sg/payments/payment-gateway/react-native-integration/standard/troubleshooting-faqs.md)
>
> Troubleshoot common error scenarios and find answers to frequently asked questions about React Native Standard integration.

Integrate with Razorpay React Native Standard SDK to accept payments from customers on your app built using React Native. The React Native Standard SDK acts as a wrapper around the Razorpay Standard SDK to build a dynamic and responsive Checkout interface for your iOS or Android application.

> [!TIP]
>
> **Update SDK**
>
> Check your current SDK version. If it is outdated, please [update the SDK](https://razorpay.com/docs/sg/payments/payment-gateway/react-native-integration/standard/troubleshooting-faqs.md#how-can-i-update-the-razorpay-react-native-standard-sdk-version) to ensure uninterrupted settlements of your funds.

> [!NOTE]
>
> **Handy Tips**
>
> This document elaborates the SDK integration steps for apps running on React Native version 0.60+. You can find the SDK integration steps for apps with [React Native version 0.59 and lower on GitHub](https://github.com/razorpay/react-native-razorpay#for-react-native-059-and-lower).

## Integration Steps

**Before you proceed:**

<ul>
  <li>Create a [Razorpay account](https://dashboard.razorpay.com/signup). </li>
  <li>Generate the [API Keys](https://razorpay.com/docs/sg/payments/dashboard/account-settings/api-keys.md#generate-api-keys) from the Dashboard. To go live with the integration and start accepting real payments, generate Live Mode API Keys and replace them in the integration.</li>
  <li>Know about the [Payment Flow](https://razorpay.com/docs/sg/payments/payment-gateway/how-it-works.md).</li>
</ul>

Choose your platform to begin integration:
