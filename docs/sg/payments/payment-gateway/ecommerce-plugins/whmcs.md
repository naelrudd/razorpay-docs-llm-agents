> Troubleshoot common error scenarios and find answers to frequently asked questions about the Razorpay WHMCS plugin.

**Before you proceed:**

* Create a [Razorpay account](https://dashboard.razorpay.com/signup).
* Understand the [payment flow](https://razorpay.com/docs/sg/payments/payment-gateway/how-it-works.md) process.
* Generate the [API Keys](https://razorpay.com/docs/sg/api/authentication.md#generate-api-keys) from the Dashboard. To go live with the integration and start accepting real payments, generate Live Mode API Keys and replace them in the integration.

## Supported Versions

We support the following versions of WHMCS: WHMCS 6, WHMCS 7 and WHMCS 8.
