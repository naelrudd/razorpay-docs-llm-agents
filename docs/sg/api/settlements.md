# Settlements

> Fetch Settlements and Settlements Recon information using Razorpay APIs.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore

Razorpay [Settlements](https://razorpay.com/docs/sg/payments/settlements) is the process in which the money received from your customers is settled to your bank account. You can manage settlements using APIs or from the [Dashboard](https://razorpay.com/docs/sg/payments/settlements/dashboard.md).

> [card] [Fetch All Settlements](https://razorpay.com/docs/sg/api/settlements/fetch-all.md)
>
> `GET` `/v1/settlements/`
>
> Retrieves all settlements.

> [card] [Fetch Settlements With ID](https://razorpay.com/docs/sg/api/settlements/fetch-with-id.md)
>
> `GET` `/v1/settlements/:id`
>
> Retrieves settlements with id.

> [card] [Fetch Settlement Recon Details](https://razorpay.com/docs/sg/api/settlements/fetch-recon.md)
>
> `GET` `/v1/settlements/recon/combined?year=yyyy&month=mm`
>
> Retrieves details of all Settlement Recon.
