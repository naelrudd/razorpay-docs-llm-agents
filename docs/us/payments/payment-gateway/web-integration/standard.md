# Web Standard Checkout Prerequisites

> Check the prerequisites before you integrate with Razorpay Web Standard Checkout.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore
🇺🇸 United States

> [card] [Troubleshooting & FAQs](https://razorpay.com/docs/us/payments/payment-gateway/web-integration/standard/troubleshooting-faqs.md)
>
> Troubleshoot common error scenarios and find answers to frequently asked questions about Web Standard Checkout Integration.

You can start accepting payments from customers on your website using the Razorpay Web Standard Checkout. Razorpay has developed the Standard Checkout method and manages it. You can configure payment methods, orders, company logo and also select custom colour based on your convenience.

> [!WARNING]
>
> **Watch Out!**
>
> Razorpay Checkout is not supported on the Internet Explorer browser.

## Integration Steps

**Before you proceed:**

<ul>
  <li>Create a [Razorpay account](https://dashboard.razorpay.com/signup). </li>
  <li>Generate the [API Keys](https://razorpay.com/docs/us/payments/dashboard/account-settings/api-keys.md#generate-api-keys) from the Dashboard. To go live with the integration and start accepting real payments, generate Live Mode API Keys and replace them in the integration.</li>
  <li>Know about the [Payment Flow](https://razorpay.com/docs/us/payments/payment-gateway/how-it-works.md).</li>
</ul>

Follow these integration steps:

> [card] [1. Build Integration](https://razorpay.com/docs/us/payments/payment-gateway/web-integration/standard/integration-steps.md#1-build-integration)
>
> Integrate Web Standard Checkout.

> [card] [2. Test Integration](https://razorpay.com/docs/us/payments/payment-gateway/web-integration/standard/integration-steps.md#2-test-integration)
>
> Test the integration by making a test payment.

> [card] [3. Go-live Checklist](https://razorpay.com/docs/us/payments/payment-gateway/web-integration/standard/integration-steps.md#3-go-live-checklist)
>
> Check the go-live checklist.
