# All Webhook Events

> List of all Payments, Partners and Payouts webhook events.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore
🇺🇸 United States

Given below is the complete list of webhook events for [Payments](https://razorpay.com/docs/us/webhooks/payments.md).

| Concept/Product | Webhook Event | Description |
| - | - | - |
| Orders | [order.paid](https://razorpay.com/docs/us/webhooks/orders.md#order-paid) | Triggered when an order is successfully paid. |
| Payments | [payment.authorized](https://razorpay.com/docs/us/webhooks/payments.md#payment-authorised) | Triggered when a payment is authorised. |
| | [payment.captured](https://razorpay.com/docs/us/webhooks/payments.md#payment-captured) | Triggered when a payment is successfully captured. |
| | [payment.failed](https://razorpay.com/docs/us/webhooks/payments.md#payment-failed) | Triggered when a payment fails. |
| Payment Downtime | [payment.downtime.started](https://razorpay.com/docs/us/webhooks/payments.md#payment-downtime-started) | Triggered at the beginning of the downtime. |
| | [payment.downtime.resolved](https://razorpay.com/docs/us/webhooks/payments.md#payment-downtime-resolved) | Triggered when a downtime is resolved. |
| | [payment.downtime.updated](https://razorpay.com/docs/us/webhooks/payments.md#payment-downtime-updated) | Triggered when a downtime is updated. |
| Refunds | [refund.created](https://razorpay.com/docs/us/webhooks/refunds.md#refund-created) | Triggered when a refund is created. |
| | [refund.processed](https://razorpay.com/docs/us/webhooks/refunds.md#refund-processed) | Triggered when the refund is successfully processed. |
| | [refund.failed](https://razorpay.com/docs/us/webhooks/refunds.md#refund-failed) | Triggered when we are not able to process a refund. |
| | [refund.speed\_changed](https://razorpay.com/docs/us/webhooks/refunds.md#refund-speed-changed) | Triggered when the refund speed is changed. |
| Payment Links | [payment\_link.paid](https://razorpay.com/docs/webhooks/payment-links.md#payment-link-paid) | Triggered when a Payment Link is paid. |
| | [payment\_link.partially\_paid](https://razorpay.com/docs/webhooks/payment-links.md#payment-link-partially-paid) | Triggered when a partial payment is made on a Standard Payment Link. |
| | [payment\_link.cancelled](https://razorpay.com/docs/webhooks/payment-links.md#payment-link-cancelled) | Triggered when a Payment Link is cancelled by you. |
| | [payment\_link.expired](https://razorpay.com/docs/webhooks/payment-links.md#payment-link-expired) | Triggered when a Payment Link expires. |
