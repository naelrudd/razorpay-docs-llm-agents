# Fetch Account Documents

> Fetch the documents uploaded for an Account using Razorpay APIs.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore
🇺🇸 United States

Use this endpoint to fetch the documents uploaded for an account. Know about the [various error responses](https://razorpay.com/docs/api/partners/errors) for this API.

```bash Curl theme={null}
curl -X GET https://api.razorpay.com/v2/accounts/acc_GP4lfNA0iIMn5B/documents \
-u <ACCESS_TOKEN> \
```

```java Java theme={null}
RazorpayClient razorpay = new RazorpayClient("[ACCESS_TOKEN]");

String accountId = "acc_LryDIBIjBDbOWy";

Account account = instance.account.fetchAccountDoc(accountId);
```

```php PHP theme={null}
$api = new Api(null, null, "<ACCESS_TOKEN>");

$accountId = "acc_M83Uw27KXuC7c8";
$api->account->fetch($accoundId)->fetchAccountDoc();
```

```javascript Node.js theme={null}

  oauthToken: "<ACCESS_TOKEN>",
```

```json Success theme={null}
{
  "business_proof_of_identification": [
```

## Path Parameters

**account\_id** `string` *required*

The unique identifier of a sub-merchant account generated by Razorpay. For example, `acc_GP4lfNA0iIMn5B`.

## Response Parameters

**business\_proof\_of\_identification** `array`

The business proof document. For more details, refer the [Appendix](https://razorpay.com/docs/partners/aggregators/onboarding-api/appendix.md).

**type** `string`

The type of document uploaded. Check the list of [Document Types](https://razorpay.com/docs/partners/aggregators/onboarding-api/appendix.md#document-type).

**document\_id** `string`

The id generated once the business proof document is uploaded.
