# API Sandbox Setup

> Sandbox setup for testing Razorpay APIs.

Available in
🇮🇳 India
🇲🇾 Malaysia
🇸🇬 Singapore
🇺🇸 United States

The Razorpay Sandbox environment allows you to test your integration without using real money. It is a crucial step before going live with your Razorpay integration.

## Steps

Follow these steps to set up the sandbox environment.

> [accordion] Generate API Keys
>
> Follow these [steps to generate API keys](https://razorpay.com/docs/us/api/authentication.md#generate-api-keys).

> [accordion] Use Sandbox URL & Client Libraries
>
> The base URL for the Razorpay Sandbox and production API is the same - `https://api.razorpay.com/v1/`. In case of certain APIs, it is `https://api.razorpay.com/v2`.
>
> For testing APIs in the sandbox environment, use the test API keys.

> [accordion] Go live
>
> After testing is complete, generate [Live API keys](https://razorpay.com/docs/us/payments/dashboard/account-settings/api-keys.md#generate-api-keys) from the dashboard. Ensure to replace the Test API keys in your integration with the Live API keys before going live. You can accept real money payments using the Live API Keys.
